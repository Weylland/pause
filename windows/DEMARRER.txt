FIL DES JOURS 1.6.1 • WINDOWS + ANDROID

Sur Windows
Décompresse cette archive dans un dossier que tu peux garder. Ouvre Pause.exe.
L’application est autonome sur Windows x64.
Pour une mise à jour, ferme Fil des jours et remplace Pause.exe au même emplacement pour que ton client MCP retrouve son chemin.

Sur Android
Installe Fil-des-jours-1.6.1.apk par-dessus la version précédente. Garde l’application existante installée pour retrouver tes données.
La page Réglages permet de connecter Google Drive ou ton PC en Wi-Fi.

Synchro Google Drive
1. Sur Windows, ouvre Réglages puis Google Drive, clique sur Importer le fichier Google (.json) et sélectionne le fichier du client de bureau téléchargé depuis Google Cloud.
2. Autorise l’accès dans le navigateur. Sur Android, ouvre Réglages, Google Drive, puis Connecter Google Drive avec le même compte.
3. La synchro se fait à l’ouverture, après une modification et toutes les deux minutes tant que l’app est ouverte. Si une même entrée a changé sur les deux appareils, la page Google Drive affiche les versions à vérifier.

Synchro Wi-Fi
1. Connecte le téléphone et le PC au même réseau local.
2. Sur Windows, ouvre Réglages puis Wi-Fi local.
3. Sur Android, ouvre Réglages, Wi-Fi local, puis Scanner le QR code et photographie le code affiché à l’écran. Tu peux aussi coller le code depuis le PC.
4. Si la Sécurité Windows demande une autorisation réseau, affiche les options et sélectionne uniquement le réseau privé.

Ensuite, laisse Fil des jours ouvert sur le PC pendant l’échange et appuie sur Synchroniser en Wi-Fi dans Réglages, Wi-Fi local sur le téléphone.
Tu peux saisir et modifier tes entrées hors ligne des deux côtés. Les changements sur des entrées différentes sont réunis. Si une même entrée diffère, le téléphone affiche les deux versions avant d’appliquer ton choix.
Si l’adresse locale du PC change, tu peux la corriger dans Réglages, Wi-Fi local ou scanner à nouveau le QR code. Garde le code d’association pour toi.

Connecteur MCP
Sur Windows, ouvre Réglages puis Connecteur pour Claude et Codex, choisis ton client et copie la configuration.
Avec Claude Desktop, ajoute l’entrée pause_pc à mcpServers dans %APPDATA%\Claude\claude_desktop_config.json, ou crée le fichier avec le bloc complet. Ferme complètement Claude Desktop et relance-le. Le connecteur apparaît dans Claude Desktop, sous + puis Connecteurs.
Avec Claude Code ou Codex, exécute la commande affichée dans PowerShell et ouvre une nouvelle session.
Pour un autre client MCP stdio, indique le chemin complet de Pause.exe comme commande et --mcp comme argument.
Le connecteur travaille avec le journal Windows, même si la fenêtre Fil des jours est fermée. Après la mise à jour, ouvre une nouvelle session de ton client MCP ou relance Claude Desktop pour charger les outils.

Dans Suivis, crée une habitude ou une pause nommée. La durée et le quota de repos sont facultatifs. Par exemple, 30 jours de vélo et 6 repos donnent un objectif de 24 jours cochés. Coche « Repos » les jours concernés. Les premiers repos dans le quota préservent la série. Les nouveaux suivis sont synchronisés avec Pause 1.6 sur les deux appareils. Sur MCP, demande par exemple « Combien de jours ai-je pratiqué l’anglais ? » ou « Coche Anglais pour aujourd’hui ».
Tu peux dire « Ajoute 82,4 kg et 250 kcal pour aujourd’hui », « Fixe mon poids cible à 80 kg » ou « Enregistre ce bilan dans Pause ». Les corrections d’aliments visent une entrée existante avec sa date et son identifiant.
La demande « Fais mon bilan des 30 derniers jours » produit une réponse dans la conversation. Si tu demandes aussi à l’IA de l’enregistrer, il apparaît dans Évolution, Bilans sur les deux appareils après la prochaine synchro.

Objectifs et rappels
Dans Réglages, ouvre Poids et calories. Synchronise pour retrouver les objectifs sur les deux appareils.
Sur Android, ouvre Rappels dans Réglages, choisis l’heure et active les notifications. Fil des jours envoie un rappel si la journée reste à renseigner. Android peut décaler l’heure de notification.
L’option Me rappeler aussi la pesée utilise la même heure et vérifie si une pesée a été saisie.

Repas sans code-barres
Dans Aujourd’hui, écris ou dicte ce que tu as mangé, sans quantité ni calories si tu veux, puis valide. Touche ou clique un aliment pour le corriger.
Sur Android, le bouton + permet de vérifier avant d’ajouter ou de garder le repas pour la synchro. Un code-barres sans calories est gardé automatiquement. Le repas apparaît avec la mention « à estimer ». Sur le PC, Fil des jours prépare la proposition avec Ciqual ou Open Food Facts. Ouvre le repas, complète les valeurs manquantes puis clique « Ajouter au journal ». Synchronise à nouveau pour retrouver les aliments sur Android.

Avec un abonnement ChatGPT éligible, ChatGPT peut chercher les aliments absents de Ciqual directement sur le téléphone. Si les limites de l’abonnement sont atteintes, les champs restent disponibles pour une saisie manuelle. Claude reste utilisable à la demande via le connecteur MCP.
Sur Android, choisis la source dans Réglages, Estimation des repas. Sur Windows, « Compléter avec ChatGPT » dans Repas à estimer cherche uniquement les références manquantes. La première utilisation ouvre la connexion ChatGPT dans ton navigateur. Avec Claude via MCP, demande de déposer une proposition pour un repas en attente, puis rouvre Repas à estimer ou clique Recharger la proposition pour la relire.
La page Évolution montre le poids, les calories ou les jours de pause sur 7, 30 ou 90 jours.

Données
Windows conserve le journal et une sauvegarde dans %LOCALAPPDATA%\Pause. Le téléphone conserve sa propre copie.
Google Drive conserve un historique dans l’espace privé de Fil des jours après autorisation. La synchronisation Wi-Fi utilise une connexion TLS sur le réseau local, via le port 43183/TCP.
